# PhishGuard Pro

Advanced Python-based phishing awareness simulation and security testing toolkit for authorized labs.

## About

PhishGuard Pro is a Python-based security awareness and testing project designed for controlled lab environments and authorized security assessments.

It aims to help security learners and analysts understand phishing-related risks through safe simulations, real-time event monitoring, and security analysis.

## Planned Features

- Interactive terminal interface
- Custom terminal banner
- Campaign management
- Unique simulation tracking links
- Real-time visit analytics
- IP, browser, device, and timestamp logging
- QR code generation
- Security event monitoring
- SQL injection and XSS input detection
- CSV and JSON report exports
- Audit logging
- Rate limiting and abuse protection

## Technology Stack

- Python
- FastAPI
- Rich
- SQLite
- HTML, CSS, JavaScript
- Pytest
